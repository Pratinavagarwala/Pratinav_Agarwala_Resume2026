# Pratinav Agarwala — Resume Website

## Preview locally
Open `index.html` in a browser. The page uses a Google Font (DM Sans and Manrope); an internet connection is needed to load those fonts. System sans-serif fallbacks are included.

## Publish with GitHub Pages
1. Add `index.html` and `style.css` to the root of your existing GitHub repository.
2. Commit and push the changes.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select your main branch and `/ (root)`, then save.
5. After deployment, GitHub will show the live website URL in the Pages section.
